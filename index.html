Expert Risk Assessment System
    How the Expert System Works

    This is a Rule-Based Expert System — a classic AI technique used in medical diagnosis, financial risk, and safety systems.

    It works like a doctor asking questions: each answer adds or subtracts from a risk score. At the end, a score threshold determines the risk level.

    Scoring Rules
    Night travel → +3 risk
    Unsafe area → +4 risk
    Rainy weather → +2 risk
    Rural road → +2 risk
    Low crowd → +2 risk
    Safe area → -1 risk
    Risk Thresholds
    Score ≥ 9 → HIGH RISK
    Score ≥ 5 → MEDIUM RISK
    Score < 5 → LOW RISK / SAFE

    Face Authentication Module

    This module uses OpenCV to detect faces via your webcam in real-time. It runs as a separate Python script outside the browser.

    How to Run Face Detection
    # Step 1: Install OpenCV
    pip install opencv-python

    # Step 2: Run the face module
    python face.py

    # Press ESC to close the camera window

    The camera window will open and detect faces in real-time. Green box = face found. To add real facial recognition (identify specific people), install DeepFace:

    pip install deepface
    For Your AI Exam — Key Concepts
    • Haar Cascade Classifier — pre-trained XML model for face detection
    • Computer Vision — processing camera frames with cv2
    • Pattern Recognition — detecting facial feature patterns
    • Real-time Processing — frame-by-frame analysis at 30fps
